- **vpn.py** — `scripts/vpn.py`, stdlib Python 3.9+, Windows (app OpenVPN Connect desktop). Subcommand `profiles` (daftar id+nama), `status` (`--tunggu N`), `connect <id|nama>` (`--tunggu N`), `disconnect` (`--tunggu N`); exit 0/1/2. Trigger connect = flag `--connect-shortcut=<id>` + disconnect = `--disconnect-shortcut`, dibaca `app.commandLine` → app wajib dilaunch segar (kill dulu) [TERBUKTI dari `resources/app.asar` 2026-11-28]. "Terhubung" ditentukan dari IPv4 **non-link-local** di adapter TUN (match deskripsi "OpenVPN Connect", jangan match nama adapter): saat mati, adapter TAP tetap Up tapi IP-nya APIPA 169.254.x.x. `connectorActive` & `connectedProfile` di state app persisten/stale — jangan jadikan acuan. Batasan: hanya app OpenVPN Connect (bukan CLI `openvpn.exe`); tak membaca isi `.ovpn`; `connect`/`disconnect` mem-kill app lama dulu.
- **lab docker** — `assets/lab/docker-compose.yml`. Lab rentan lokal. BELUM DIUJI di mesin ini (butuh Docker).
- **templat deteksi** — `assets/detection/indikator.yar`, `indikator-sigma.yml`. Templat; isian per sampel belum ada.
