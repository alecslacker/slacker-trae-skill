## 1. Standar Komunikasi

- Bahasa Indonesia natural (bukan terjemahan kaku). Panggil user "Mas Wondho".
- Awam-first: hindari jargon tanpa penjelasan. Beri analogi bila perlu.
- Satu pertanyaan per giliran; pakai opsi pilihan bila memungkinkan (mudah dijawab).
- Keyword kontrol: KERJAKAN (1 task lalu tunggu), LANJUT, ULTRATHINK, KONSUL (diskusi saja—dilarang edit file), REVISION, EXPLAIN, Stop, Undo.

## 2. Anti-AI-Slop (WAJIB untuk semua output desain/UI/tulisan)

1. **Design System Eksplisit** — sebelum coding UI: font spesifik (bukan "sans-serif"), warna hex konkret, spacing grid 8px, radius hierarchy, shadow bertingkat, motion (durasi + easing). Tanya user jika tidak spesifik.
2. **Reference-Driven** — "layout seperti Linear/Vercel/Stripe" > "desain modern". Screenshot referensi → analisis token (warna/font/layout).
3. **Proses Sequential** — rough layout → hierarki → warna+tipografi → interaksi → aksesibilitas → edge state → kritik final.
4. **Edge State Hidup** — tiap layar wajib punya state: kosong (copy + aksi, mis. "Belum ada proyek. Mulai dari template atau buat dari nol."), loading (skeleton match layout), error (jelaskan apa yang salah + solusi), offline, success. DILARANG: "No data found", "Something went wrong", "Loading..." polos.
5. **Detail Pembeda** — 1 set icon konsisten, radius konsisten, whitespace intentional, micro-interaction (hover/focus/active/disabled) di SEMUA elemen interaktif. Dilarang: emoji berlebihan, gradient tanpa tujuan, "Lorem ipsum", placeholder text.
6. **AI Test** — sebelum klaim desain selesai: layout bisa ditebak = AI? elemen punya tujuan emosional? spacing intentional? typography berkarakter? edge state ber-personality? gambar konsisten? Jika ya-jawaban = "ini AI" → redesign.
7. **Image Kontekstual** — gambar/generate WAJIB: tujuan penggunaan + style konsisten satu project + palette hex + mood + komposisi. Konsistensi antar gambar.

## 3. Standar Kode & Keamanan

- Input validation; query parameterized/ORM — dilarang raw SQL.
- Secret di `.env`, tidak pernah hardcode.
- Akses kontrol ketat untuk resource sensitif.
- WordPress: nonce + `esc_html/esc_attr/esc_url`, prefix `dci_`.
- Laravel: CSRF, `{{ }}` auto-escape, Form Request validation.
- Node/Express: HttpOnly cookies, type-safe schema.
- Komentar kode Bahasa Indonesia.

## 4. Stack Favorit (deteksi package.json/composer.json dulu, jangan asumsi)

- Backend: **Laravel** (preferensi #1). Filament untuk admin, Livewire 3 untuk UI reaktif PHP-only.
- Frontend: Laravel + Inertia + React + shadcn/ui + Tailwind CSS (default modern/SPA).
- Database: MySQL/MariaDB utama; PostgreSQL opsi kedua.
- Server: Ubuntu + OpenLiteSpeed + aaPanel. Lokal: Laragon.
- WordPress plugin dev (prefix dci_) hanya jika project minta.

## 5. Skill Inti yang Sering Dipakai (ringkas)

### PRD Builder (prd-builder)
- Pandu user buat PRD 8 section: Overview → Requirements → Core Features → User Flow+Edge State → Architecture → Database → Tech Stack → **Design System** (anti-slop: vibe, referensi, warna, font, mode, radius/motion).
- Awam-first, satu pertanyaan per giliran, konfirmasi per section.
- Output: PRD → Implementation Plan → Task Breakdown → Design Spec (dengan Edge State + AI Test gate). Simpan di `.trae/documents/`.

### Generator Gambar (byteplus-seedream5)
- API BytePlus ModelArk langsung (MCP byteplus-image hanya Seedream 4.x).
- **Dola-Seedream-5.0-pro** (`dola-seedream-5-0-pro-260628`): kualitas maks, teks Bahasa Indonesia native, precision editing, layer. Resolusi 1K–2K. $0.045/gbr.
- **Dola-Seedream-5.0-lite** (`seedream-5-0-260128`): estetika terbaru, batch, hemat, 2K–4K. $0.035/gbr.
- Jalankan: `C:\Python312\python.exe <path>/byteplus-seedream5/scripts/seedream5_generate.py --prompt "..." --model pro|lite --size 2K`
- Key di env `ARK_API_KEY` (user-level registry). Jangan pernah print key.

### Frontend Design
- Bold aesthetic direction: pilih nada ekstrem (brutalist, luxe, editorial, organic, dll), bukan rata-rata.
- Dilarang font generik (Inter/Roboto/Arial), gradient ungu di atas putih, layout yang bisa ditebak.
- Typography khas: display font unik + body font refined. Motion terarah, komposisi asimetris.

### Web Interface Guidelines (web-design-guidelines)
- Untuk review UI vs guidelines resmi: fetch `https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md`, review file, output format `file:line`.

### Playwright Best Practices
- E2E/component/API/visual/a11y testing: gunakan locator user-facing (`getByRole`/`getByLabel`), hindari selector rapuh, auto-wait, Page Object Model, fixtures untuk setup/teardown, handle flaky test via trace viewer.

### Blog Engine (claude-blog)
- Tulis/rewrite/audit artikel: dual-optimized Google + AI citations; E-E-A-T; fakta ber-sumber (dilarang fabrikasi statistik); struktur heading H1→H2→H3; alt text wajib; chart beragam jenis.
