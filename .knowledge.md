## 1. Anti-AI-Slop (WAJIB untuk semua output desain/UI/tulisan)

1. **Design System Eksplisit** — sebelum coding UI: font spesifik (bukan "sans-serif"), warna hex konkret, spacing grid 8px, hierarki radius, shadow bertingkat, motion (durasi + easing). Tanyakan ke user bila tidak spesifik.
2. **Reference-Driven** — "layout seperti Linear/Vercel/Stripe" mengalahkan "desain modern". Dari screenshot referensi, analisis token: warna, font, layout.
3. **Proses Berurutan** — rough layout → hierarki → warna+tipografi → interaksi → aksesibilitas → edge state → kritik final.
4. **Edge State Hidup** — tiap layar wajib punya state kosong (copy + aksi, mis. "Belum ada proyek. Mulai dari template atau buat dari nol."), loading (skeleton yang match layout), error (jelaskan apa salah + solusinya), offline, dan success. Dilarang: "No data found", "Something went wrong", "Loading..." polos.
5. **Detail Pembeda** — satu set icon konsisten, radius konsisten, whitespace intentional, micro-interaction (hover/focus/active/disabled) di semua elemen interaktif. Dilarang: emoji berlebihan, gradient tanpa tujuan, "Lorem ipsum".
6. **AI Test** — sebelum klaim desain selesai, tanyakan: layout bisa ditebak? elemen punya tujuan emosional? typography berkarakter? edge state ber-personality? Jawaban "ini AI" pada salah satu = redesign.
7. **Gambar Kontekstual** — generate gambar wajib punya: tujuan penggunaan, style konsisten satu project, palette hex, mood, komposisi.

**Aksesibilitas**: kontras minimal AA (4.5:1 teks normal, 3:1 teks besar), focus visible, navigasi keyboard, tap target ≥44px. Mobile: reflow, bukan sekadar shrink — breakpoint ditentukan saat konten patah, bukan angka default.

## 3. Skill: PRD Builder (prd-builder)

- Pandu user membangun PRD 8 section: Overview → Requirements → Core Features → User Flow + Edge State → Architecture → Database → Tech Stack → **Design System** (vibe, referensi, warna, font, mode, radius, motion).
- Metode: awam-first, satu pertanyaan per giliran, konfirmasi tiap section.
- Output berantai: PRD → Implementation Plan → Task Breakdown → Design Spec (dengan Edge State + AI Test gate). Simpan di `.trae/documents/`.

## 7. Skill: Testing (playwright-best-practices)

- Locator user-facing (`getByRole`, `getByLabel`) — hindari selector rapuh (XPath/CSS bergantung DOM).
- Auto-wait bawaan; Page Object Model untuk reuse; fixtures untuk setup/teardown.
- Test flaky: reproduksi via trace viewer, jangan langsung tambah sleep.
